# Week 8 — Midterm written examination

**Software Security 2 (02005094) · one 150-minute slot.** Administration 10 + written working/checking 130 + collection 10. The current [specimen paper](exam.md) has ten questions, raw 100 split Basic 50 / Technical 50; it contributes **8%** of the course (4 Basic + 4 Technical).

Scope: Weeks 1–6: threat modeling, tooling, application crypto misuse/migration, injection, XSS and authentication/authorization. Correction, appropriate controls and limits are assessed.

This is a paper exam: you write your answers on the exam paper, with no computer. The real exam paper is handed out at the exam; the specimen is for practice only. The exact date, time, room and permitted aids will be in the official exam notice. [Agenda](../../AGENDA.md) · [Syllabus](../../syllabus.md).
